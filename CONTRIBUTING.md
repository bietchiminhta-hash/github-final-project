# Contributing

All contributions are welcome! This includes bug reports, bug fixes, documentation improvements, enhancements, and ideas.

## How to Contribute

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes
4. Commit your changes with a clear message
5. Push to your fork
6. Open a Pull Request

## Reporting Bugs

If you find a bug, please open an issue describing:
- What you expected to happen
- What actually happened
- Steps to reproduce the issue

## Suggesting Enhancements

Ideas and enhancement suggestions are welcome. Please open an issue to discuss before starting significant work.

## Documentation

Improvements to documentation are always appreciated, no matter how small.
